(debugging/research sessions can produce zero commits — see e.g. the
SSH-auth troubleshooting on 2026-09-04 below).

Append one line per session at the top, newest first:

```

```

Estimate the times if you didn't note them live — rough is still far better
than reconstructing from commit gaps after the fact.
